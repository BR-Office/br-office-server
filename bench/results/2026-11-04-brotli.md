# 2026-11-04 · brotli instead of gzip for fonts and scripts (nginx) · home profile, HTTPS

Baseline on both sides: the merged state (editor-only preloader, font styles on demand). A = nginx gzip (as packaged). B = nginx brotli: brotli_static with files precompressed at quality 11, brotli on at level 5 for the rest. HTTPS on both sides (Chromium only accepts brotli on secure origins). ## Reading

- The floor is now centred on zero (painted +0.08 s median, range ±0.6 s, 4/8 pairs each way).
- Brotli: document loaded −0.51 s (8/8 pairs, whole range outside the floor), last paint −0.41 s (7/8). 3.7 MB less per cold open: fonts 6.96 → 5.51 MB, scripts 8.84 → 6.48 MB, app 1.73 → 1.25 MB.
- Where it lives: nginx configuration and the brotli module come from the Document Server package (upstream Euro-Office/document-server-package, common/documentserver/nginx/includes/ds-common.conf.m4), which BR-Office has no fork of yet.

## Correction to the earlier runs of this day

The earlier runs used plain ABBA order, which lined up with a server effect of period four runs and gave side B about −0.5 s for free (old floor: 7/7 pairs). The editor-only preloader result (−2.1 s, −1.4 s with the exact source) is far beyond that and stands. The font-styles result should be read as about −0.5 s on document loaded (−0.93 s measured minus the −0.41 s old-floor bias on the same mark), with the last paint inside the noise.
