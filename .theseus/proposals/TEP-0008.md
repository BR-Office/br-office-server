## Problem
Acceptance often does not exercise what the packet delivers: PKT-0042, 0043, 0044, 0047, 0048 friction (`ref: acceptance`). The resulting defects were caught only by review (PKT-0042, 0046, 0047 rejected at first review). Integration merges dropped delivered content (PKT-0059, PKT-0067).

## Proposed change
1. Work-packet spec: "Every packet that creates an oracle, script or data file has at least one acceptance command that runs or reads that file (not only `test -s`)."
2. `theseus validate`: "fail when a file listed in a done packet's delivered diff no longer exists on the main branch and no later packet removed it."

## Hypothesis
"First-review approval returns from 81% to at least 92%, and friction lines with `ref: acceptance` or integration loss fall from 7 to at most 2 per 27 records, without raising median done duration above 10 minutes."

## How to verify
First-review approval, count of friction lines citing acceptance or merge loss, median `duration_min` of done packets in AUD-4. Minimum sample: 20 done packets.

## Risks
Acceptance needing a running service fails in the factory (see TEP-0002 `requires`); watch blocked records naming the environment.
