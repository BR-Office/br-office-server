## Problem
- `approved_first_review` is true on records whose `rejection_reasons` contain an acceptance-gate rejection: PKT-0109, 0137, 0149 (AUD-7), and similar in AUD-4, AUD-5, AUD-6 (PKT-0127). First-review approval reads 81% when it is 67%.
- `out_of_context_reads` is null on every record for seven audits (25/25 in AUD-7).
- Planner file estimates miss method files: 7/7 planner records under-estimate files by 1–5 (0108 est 2 actual 7; 0115 est 1 actual 4); 0109 friction says the budget counts packet, friction and spawn files.

## Proposed change
In §4.1: "`approved_first_review` is true only when the first delivery passed every gate and the review with no rejection of any kind." Remove `out_of_context_reads` from the required fields (keep it optional). In §6: "the planner's `estimate.files` counts the packet file, the friction file and any spawn request it expects."

## Hypothesis
"In the next 20 records, 0 records have `approved_first_review: true` with a non-empty `rejection_reasons`, and the median |actual/estimated − 1| on files of planner records falls from ≥ 1.0 to below 0.5, with no change in planning cost per packet (+5% at most)."

## How to verify
Count records with true + non-empty reasons (expect 0). Median file deviation on planner records (min. 5). Planner cost per packet vs AUD-7.

## Risks
Approval rate will look worse; that is the correction, not a regression. Watch that agents do not skip spawns to fit the file estimate (spawned per packet should stay ≈ 0.36).
