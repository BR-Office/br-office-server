## Problem
In AUD-6, 3 of 13 run records blocked on a Goal the target could not reach: PKT-0108 (needs external/core, target empty), PKT-0111 (bar "LoadDoc drop > run spread", cost in Toolbar.template outside target, 3 attempts), PKT-0112 (needs Toolbar.js). $15.30 = 60% of period spend, nothing delivered. PKT-0105, 0108, 0112 report 20–60% timing spread on the shared VM.

## Proposed change
Add to the work-packet spec, Goal section: "A Goal with a numeric bar states its protocol (paired A/B or ABBA, number of pairs, statistic, e.g. median paired delta) and the threshold in that statistic. The planner lists in `target.files` every file the Goal's change requires, or narrows the Goal. Lint warns on a Goal with a number and no protocol." Reviewers' 'bar not met because outside target' counts as an external blocker on first occurrence (TEP-0001).

## Hypothesis
"Blocked records whose block names a file outside target or an unreachable bar fall from 3 of 13 run records (AUD-6) to at most 1 in the next 20 run records, and blocked cost falls below 20% of spend, with first-review approval not below 75%."

## How to verify
AUD-7 classifies `block_reason.text` and rejection reasons; blocked cost share; approval rate. Minimum 20 run records (discards excluded).

## Risks
Planners narrow Goals to trivially reachable bars; watch measured gain per perf packet in the diagnosis files.
